## 🧰 Using Encrust: First Steps

A typical workflow in Encrust has four stages.

1. Import your model. Choose an STL or 3MF file from your computer. Wait for the model to appear in the workspace.

2. Add supports. Use the support tools to place supports under overhanging areas. Supports help prevent parts of the model from sagging or detaching during printing. Encrust provides automatic and manual support options.

3. Hollow the model if needed. If your model is solid and large, hollowing can reduce resin use. Hollowing creates a shell inside the model while leaving the outside shape unchanged. Use this feature carefully and add drain holes where appropriate so uncured resin can escape.

4. Run print-failure analysis. This step reviews your model and supports for common problems. Fix any issues that are flagged before you export the file.

5. Export the print-ready file. Save the prepared model in a format your resin printer can use. Follow your printer’s normal workflow to load the file and begin printing.

## 🔍 Understanding Print-Failure Analysis

Print-failure analysis is a check that looks for conditions that often cause resin prints to fail. For example, it may look for areas of the model that are unsupported, places where the model connects weakly to the build plate, or geometry that could trap resin. The analysis does not guarantee a perfect print, but it helps you make better decisions before you start printing. Treat it as a helpful review step rather than a replacement for your own judgment.

## 🦿 Supports and Hollowing Explained

Supports are thin structures that hold up parts of your model while it prints. In resin printing, the model is built layer by layer, and overhanging areas need support so they do not sag or peel away. Encrust lets you add supports automatically or place them yourself.

Hollowing turns a solid model into a shell with a hollow interior. This saves resin and can make large models easier to print. However, hollow models need drain holes so that unused resin can flow out after printing. Without drain holes, trapped resin can cause problems later. Encrust provides hollowing tools, and you should review the result carefully before exporting.

If Encrust does not start, first make sure the download completed fully. Try opening the application again. If the problem continues, restart your computer and try once more.
